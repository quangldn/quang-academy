# Từ điển thuật ngữ DWDM (Việt–Anh)

> Quy ước: giữ nguyên thuật ngữ tiếng Anh (OSNR, ROADM...) vì đó là ngôn ngữ làm việc thực tế; cột giải thích bằng tiếng Việt.

## A–E

| Thuật ngữ | Viết tắt của | Giải thích ngắn |
|---|---|---|
| **Attenuation** | — | Suy hao — công suất giảm khi truyền qua sợi/thành phần (dB). |
| **ASE** | Amplified Spontaneous Emission | Nhiễu phát xạ tự phát do bộ khuếch đại quang sinh ra; nguồn chính làm giảm OSNR. |
| **AWG** | Arrayed Waveguide Grating | Linh kiện ghép/tách nhiều bước sóng dựa trên ống dẫn sóng mảng. |
| **Baud rate** | — | Số ký hiệu/giây (GBd); nhân với bits/symbol và 2 (DP) ra bit-rate. |
| **BER** | Bit Error Rate | Tỉ lệ bit lỗi; đo trước (pre-FEC) và sau (post-FEC) sửa lỗi. |
| **CD** | Chromatic Dispersion | Tán sắc màu — các bước sóng đi với tốc độ khác nhau, làm giãn xung (ps/nm/km). |
| **CDC** | Colorless / Directionless / Contentionless | Đặc tính ROADM linh hoạt về bước sóng/hướng/tranh chấp. |
| **Coherent** | — | Kỹ thuật thu dùng cả biên độ, pha, phân cực + DSP; nền tảng của 100G+. |
| **CWDM** | Coarse WDM | WDM khoảng cách kênh rộng (20 nm), rẻ, ít kênh, cự ly ngắn. |
| **DP** | Dual Polarization | Phân cực kép — gửi 2 luồng độc lập trên 2 phân cực vuông góc. |
| **DSP** | Digital Signal Processing | Xử lý số ở máy thu coherent; bù CD/PMD, tách phân cực. |
| **DWDM** | Dense WDM | WDM mật độ cao (khoảng 50/100 GHz), nhiều kênh trong C/L-band. |
| **EDFA** | Erbium-Doped Fiber Amplifier | Khuếch đại quang bằng sợi pha Erbium; hoạt động vùng C/L. |

## F–O

| Thuật ngữ | Viết tắt của | Giải thích ngắn |
|---|---|---|
| **FEC** | Forward Error Correction | Sửa lỗi chủ động; hard/soft-decision, cho coding gain lớn. |
| **FlexO** | Flexible OTN | Giao diện OTN linh hoạt cho tốc độ cao (beyond 100G). |
| **FWM** | Four-Wave Mixing | Hiệu ứng phi tuyến tạo tần số ký sinh khi nhiều kênh trộn nhau. |
| **GSNR** | Generalized SNR | SNR tổng quát gộp cả nhiễu ASE và phạt phi tuyến — chỉ số thiết kế coherent. |
| **IMDD** | Intensity Modulation / Direct Detection | Điều chế cường độ, thu trực tiếp; hệ "tiền coherent". |
| **IPoDWDM** | IP over DWDM | Cắm optic coherent thẳng vào router, bỏ transponder rời. |
| **NF** | Noise Figure | Chỉ số nhiễu của bộ khuếch đại (dB); càng thấp OSNR càng tốt. |
| **OADM** | Optical Add-Drop Multiplexer | Thêm/tách một số bước sóng tại một site. |
| **OSA** | Optical Spectrum Analyzer | Máy phân tích phổ quang; đo mức từng kênh và OSNR. |
| **OSC** | Optical Supervisory Channel | Kênh giám sát quang riêng để quản lý thiết bị dọc tuyến. |
| **OSNR** | Optical Signal-to-Noise Ratio | Tỉ số tín hiệu/nhiễu quang (dải 0.1 nm); quyết định tuyến chạy được hay không. |
| **OTN** | Optical Transport Network | Lớp truyền tải chuẩn ITU-T G.709 (OTU/ODU/OPU). |

## P–Z

| Thuật ngữ | Viết tắt của | Giải thích ngắn |
|---|---|---|
| **PCS** | Probabilistic Constellation Shaping | Điều chỉnh xác suất các điểm constellation để tối ưu dung lượng/cự ly. |
| **PMD** | Polarization Mode Dispersion | Tán sắc do phân cực; giới hạn tốc độ trên sợi cũ. |
| **QAM** | Quadrature Amplitude Modulation | Điều chế biên độ vuông góc; 16/32/64QAM = nhiều bit/symbol. |
| **Raman (DRA)** | Distributed Raman Amplification | Khuếch đại phân tán ngay trong sợi truyền; cải thiện OSNR. |
| **ROADM** | Reconfigurable OADM | OADM cấu hình lại từ xa bằng WSS; xương sống mạng mesh. |
| **RSA / RWA** | Routing & Spectrum/Wavelength Assignment | Bài toán chọn đường + cấp phổ/bước sóng trong mạng. |
| **SMF** | Single-Mode Fiber | Sợi đơn mode (G.652...); môi trường của DWDM đường dài. |
| **SPM / XPM** | Self / Cross Phase Modulation | Hiệu ứng phi tuyến do chính kênh / kênh lân cận gây méo pha. |
| **SRLG** | Shared Risk Link Group | Nhóm liên kết cùng chịu một rủi ro vật lý; quan trọng khi thiết kế bảo vệ. |
| **WSS** | Wavelength Selective Switch | Chuyển mạch chọn bước sóng — trái tim của ROADM. |
| **ZR / ZR+** | 400ZR / OpenZR+ / 800ZR | Chuẩn optic coherent pluggable (OIF) cho IPoDWDM. |

<Callout type="note" title="Đóng góp">

Thiếu thuật ngữ? Đây là tài liệu sống — thêm vào khi khoá học mở rộng.

</Callout>
